# Procesos Estocásticos / Stochastic Processes

A repository for Stochastic Processes (SP) workshops and practical exercises.

## About / Acerca de

This repository contains workshop materials, notes, and implementations related to the study of **Stochastic Processes**. Stochastic processes are mathematical models used to describe systems that evolve over time in a random or probabilistic manner. They are fundamental tools in fields such as:

- Finance and economics (stock prices, interest rate models)
- Engineering (signal processing, reliability analysis)
- Biology (population dynamics, epidemiology)
- Physics (Brownian motion, quantum mechanics)
- Computer Science (queuing theory, machine learning)

## Key Concepts / Conceptos Clave

- **Stochastic Process**: A collection of random variables indexed by time or space, `{X(t), t ∈ T}`.
- **Markov Property**: A process where the future state depends only on the current state, not on past states.
- **Stationary Process**: A process whose statistical properties do not change over time.
- **Ergodicity**: A property where time averages equal ensemble averages.
- **Martingale**: A process where the expected future value equals the current value.
